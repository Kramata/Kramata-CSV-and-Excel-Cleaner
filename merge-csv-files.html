How it works

  1. Add your CSV files by dropping them on the box or clicking Choose files.
  2. Click Merge files. Columns are lined up by name, so their order in each file doesn’t matter.
  3. Check the summary and download merged.csv. It’s saved as UTF-8, so Excel shows accented characters correctly.

Why not just copy *.csv?

Windows copy *.csv combined.csv glues the files together as plain text. Every file’s header row repeats inside the result, a file that doesn’t end with a line break has its last row stuck onto the first row of the next file, and if one file has its columns in a different order, its values land under the wrong headers. Our guide to merging CSV files in Windows CMD shows each problem.

FAQ

Are my files uploaded? No. The merge runs in your browser, so your files are read and merged on your own device and the merged file is created there too. Nothing from your files is sent to Kramata or anyone else. We only count that a merge happened (how many files and a rough row count), never file names or contents.

How big can the files be? There's no fixed limit. It depends on your computer's memory and your browser, and a few hundred megabytes in total usually works. For multi-gigabyte files, the Kramata desktop app for Windows is the better fit.

What if the files have different columns? Columns are matched by name, ignoring upper and lower case and extra spaces, so the order of columns doesn't matter. A column that only some files have is kept and left blank for the rows from the other files. The summary shows which columns each file was missing.

Can it merge Excel files? No, this tool merges CSV and TXT files only. To merge Excel files (.xlsx or .xls), use the Kramata desktop app for Windows, or save each sheet as CSV first.

Is it really free? Yes. There's no sign-up, no limit on how often you use it and no watermark on the result. It's made by Kramata, a Windows app for cleaning the same spreadsheets every week, but the tool works without it.
