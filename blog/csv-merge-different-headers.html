How to merge CSV files when the headers don’t match

Updated November 5, 2026

Match columns by name, then decide what to do with the names that differ.

Short answer: merge by column name, not by position, and rename the columns that are spelled differently so they line up. Tools that stack files by position, like Windows copy *.csv, put values under the wrong headers without any warning.

The three ways headers go wrong

  • Different order. March has Name, Amount; April has Amount, Name. Matching by name fixes this on its own.
  • Different spelling or case. “First Name”, “first name”, “first_name”. Case is easy to ignore; spelling needs a rename.
  • Extra or missing columns. One export adds “Discount”. A name-based merge keeps it and leaves it blank for the files that don't have it.
  • Rows above the header. Some exports start with a title or a date line. That row has to be skipped, or it becomes the header.

Why copy *.csv gets it wrong

CMD's copy joins the files as raw text. It doesn't know what a column is, so every file's header row repeats in the output and any file with a different column order is silently misaligned. It's only safe when every file has exactly the same columns in the same order. (Our CMD merge guide shows the details.)

Method 1: Power Query (Excel)

In Excel, Data › Get Data › From File › From Folder › Combine stacks a folder of files. Appending tables in Power Query matches columns by name, and a column that exists in only some files is filled with null for the rest. Rename differently spelled columns in the transform before the combine so they become one column. Check the step that expands the combined table: its column list comes from the sample file, so a column that appears only in later files can be left out.

Method 2: Python (pandas)

import pandas as pd, glob
fix = {"first_name": "First Name", "first name": "First Name"}
frames = [pd.read_csv(f).rename(columns=fix) for f in glob.glob("exports/*.csv")]
pd.concat(frames, ignore_index=True).to_csv("combined.csv", index=False)

pd.concat lines frames up by column name; the rename mapping folds the spelling variants together. Add skiprows= to read_csv for files with a title row above the header.

Method 3: Kramata (no code)

  1. Open one of the files and build the cleanup it needs. Save it as a recipe.
  2. Click Batch, pick all the files, and choose Merge into one.
  3. Kramata stacks the files by column name, ignoring differences in case and order. A column missing from a file is left blank for that file's rows.
  4. A column spelled differently (first_name vs First Name) comes through as its own column. Add a Merge columns step with “skip empty values” on to fold the two into one, and save the recipe again.
  5. Next week, run the same batch on the new files.

For Excel files, batch reads the first sheet and uses the fullest row near the top as the header, so a title row above it is usually skipped. CSV files are read with their first row as the header. If a file needs a different header row, open it on its own: Kramata lets you choose the header row(s) and the row where the data starts.

Doing this every week? Kramata saves the steps as a recipe, so next week’s file is open, apply, export.

FAQ

Why are my columns misaligned after merging CSV files? The tool stacked the files by position, not by column name. Windows copy *.csv does this, so any file with a different column order ends up under the wrong headers.

Can I merge CSV files with different column orders? Yes, if the tool matches by name. Power Query, pandas and Kramata all line columns up by name, so the order in each file doesn't matter.

What happens to a column that only some files have? In a name-based merge it is kept, and rows from the files without it are left blank.

How do I combine First Name and first_name into one column? Rename one to match the other before merging (Power Query or pandas), or in Kramata add a Merge columns step with skip empty values on, which folds the two into one column.

What if a file has a title row above the header? Skip it: in pandas use skiprows, in Power Query remove the top rows before promoting headers, and in Kramata choose the header row when you open the file. Kramata's batch also skips a title row in Excel files by using the fullest row near the top as the header.
