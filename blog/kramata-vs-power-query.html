Kramata vs Power Query

Updated November 5, 2026

Where each one is better, and who each is for.

Short answer: Power Query is the more powerful tool and it's already in Excel. Choose it if you work in Excel and are happy to learn its editor. Kramata is narrower and simpler: plain-language steps, a saved recipe and batch output to files. Choose it if the people doing the work don't want to learn Power Query.

Where Power Query is better

  • It's already there. Power Query is built into Excel for Windows (Data › Get & Transform) and into Power BI, with no extra cost beyond Excel.
  • Far more data sources. Files and folders, databases, web pages, SharePoint and more. Kramata reads CSV and Excel files only.
  • More ways to join. Merge Queries offers left, right, full outer, inner and anti joins, plus fuzzy matching. Kramata's merge does left and inner joins on exact matches.
  • Unpivot Other Columns. Power Query can unpivot “everything except these columns”, so next month's new column is picked up automatically. Kramata's Unpivot step stores a fixed list of columns.
  • A full language underneath. When the buttons run out, M code can do almost anything. Kramata's steps are deliberately limited.
  • Refresh in place. Results stay connected to the workbook, pivot tables and charts that use them.

Where Kramata is better

  • No editor to learn. Steps are written in plain language (“Remove duplicates”, “Fix dates”), each with a live preview of what it changed.
  • Output as files. Batch writes one cleaned file per input to a folder, or merges them into one file. Power Query's results land in a workbook.
  • A portable recipe. The steps are a small .json file you can send to a colleague; it isn't tied to a workbook or a file path on your machine.
  • Renamed columns on re-run. When you apply a recipe to a new file that's missing a column it uses, Kramata asks which column it is (in Batch, it reports the missing column and skips the steps that need it). Power Query stops the refresh with an error until the step is edited.
  • Flagged rows. Rows that fail a check can go to a separate review list instead of being dropped silently.
  • No Excel needed. Kramata is a standalone Windows app and isn't held to Excel's 1,048,576-row worksheet limit (export very large results as CSV).

Who each is for

Power Query is for Excel users who build reports from several sources, want refreshable tables inside a workbook, and are willing to learn the editor (and some M) to get there.

Kramata is for people who get the same CSV or Excel export every week, want it cleaned the same way every time, and want to hand that job to a colleague without teaching them Power Query.

Doing this every week? Kramata saves the steps as a recipe, so next week’s file is open, apply, export.

FAQ

Is Power Query free? Power Query is included with Excel for Windows and with Power BI, so there is no extra cost if you already have Excel. Kramata is free for single files; unlimited batch processing is a one-time $49.

Is Kramata a replacement for Power Query? Not for everyone. Power Query has more data sources, more join types and a full language. Kramata covers the common cleanup steps in plain language for people who don't want to learn Power Query.

Which handles renamed columns better? Power Query stops the refresh with an error until you edit the step. Kramata asks you which column is which when you apply the recipe and saves the answer as a rename step.

Can Kramata connect to databases or SharePoint? No. Kramata reads CSV and Excel files only. Power Query is the better choice if your data comes from databases or online sources.

Does either upload my data? No. Both work on local files on your computer. Kramata never uploads your files.
