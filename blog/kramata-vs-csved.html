Kramata vs CSVed

A free manual grid editor vs a recipe that repeats itself automatically.

CSVed is a long-standing, free Windows CSV editor — open a file, see it as a grid, and edit, split, join, or clean it by hand. It's a genuinely useful tool for a quick manual fix. Kramata solves a different problem: the file that needs the same cleanup applied every time it arrives. Here's an honest breakdown.

The short version

  • CSVed is a free, standalone CSV grid editor. You open a file and edit it directly — trim, split/join columns, remove duplicates, search and replace — with repeat tasks handled by writing your own macros or scripts.
  • Kramata is also standalone, but built around a different idea: record the cleanup once as a plain-language recipe, then re-run it on any new file — or a whole folder of them — in one click. Free for single files; batch is a one-time $29.

Pick CSVed if…

  • It's a one-off file and you just want to open it, eyeball it, and hand-edit a few cells or rows directly.
  • You're comfortable writing a macro or script when a task needs to repeat.
  • You want it for free with no feature gated behind a paid tier.

Pick Kramata if…

  • The same file, or a folder of them, arrives on a schedule and you want the identical cleanup applied without writing anything.
  • You want invalid rows flagged for review automatically, not hunted down by hand in a grid.
  • You need native Excel support (.xlsx/.xlsm/.xls), not just CSV.
  • You want a portable recipe file you can hand to a colleague who isn't comfortable writing a script.

FAQ

Is CSVed free? Yes — freeware, no paid tier. Kramata is free for single files; batch processing across a folder is a one-time $29.

Can CSVed clean the same way automatically next time? CSVed is built around hand-editing a grid; repeat tasks can be scripted with macros. Kramata makes repeatability the whole product — build the steps once as a plain-language recipe, apply it to next month's file in one click, no scripting.

Does CSVed handle Excel files? CSVed is CSV/delimited-text-first — it can export to Excel and other formats, but its native editing is CSV. Kramata reads and processes CSV, modern Excel (.xlsx/.xlsm), and legacy binary Excel (.xls) directly.

Can either batch process a whole folder of files? Kramata has folder batch built in — same recipe, every file, one run. CSVed is built for one file at a time; automating it across many files means writing your own macro or script.

Does either tool upload my data? No. Both are Windows desktop apps that run entirely on your computer.
