What’s the best tool for cleaning the same messy CSV files every week?

Updated November 5, 2026

Answer first, then the options, then how to choose.

Short answer: use a tool that saves your cleaning steps and re-runs them on the next file, instead of one where you repeat the clicks. If you already live in Excel, that's Power Query. If you write code, it's a Python script. If you want neither formulas nor code, a recipe-based app such as Kramata does it in plain-language steps.

A weekly file is a different problem from a one-off file. The cleanup itself is usually small: trim spaces, fix dates, remove duplicates, drop a few columns. What costs time is doing it again every week, doing it the same way, and handing it over when you're away. So the question to ask of any tool is not “can it clean this?” but “can it repeat this exactly, next week, for someone else?”

What to look for

  • Saved steps. The cleanup is stored and re-applied, not redone by hand.
  • Matching by column name. Next week's export will move or rename a column sooner or later.
  • A preview. You can see what each step changes before you export.
  • Easy hand-over. A colleague can run it without learning a language.
  • Room for size. Exports grow; Excel worksheets stop at 1,048,576 rows.
  • Where the data goes. For customer or financial data, a tool that runs on your own computer avoids uploading it.

How the weekly job looks in Kramata

  1. Open this week's file and add the steps it needs: trim spaces, fix dates, remove duplicates, rename or drop columns.
  2. Check the preview; each step shows what it changed.
  3. Export the cleaned file, then click Save recipe.
  4. Next week, open the new file and click Apply recipe. If a column was renamed, Kramata asks you which column it is.
  5. Several files at once? Use Batch to clean them separately or merge them into one.

Rows that fail a check (for example a missing email or a negative amount) can be moved to a separate review list instead of disappearing. FAQ

What is the best tool for cleaning the same CSV every week? One that saves your cleaning steps and re-runs them on the next file. Power Query suits Excel users, a Python script suits people who code, and Kramata suits people who want neither formulas nor code.

Can Excel remember my cleaning steps? Power Query can: it saves the steps in the query and re-runs them on Refresh. Commands like Remove Duplicates and Text to Columns change the sheet once and remember nothing.

Is there a way to do this without code? Yes. Power Query's buttons cover common steps without M code, and Kramata is built entirely around plain-language steps saved as a recipe.

What if next week's file has a renamed column? Power Query stops the refresh with an error until you edit the step. Kramata asks you which column is which when you apply the recipe, then saves that choice as a rename step.

Does the data leave my computer? Power Query, Python, OpenRefine and Kramata can all run locally. Kramata processes everything on your computer and never uploads your files.
