Privacy

Your data never leaves your computer. Only anonymous app usage does — and you can turn that off.

Stays 100% local (never sent)

  • The files you open and everything in them — names, paths, sheet/column names, and every cell value.
  • Your recipes and where you save outputs.
  • All processing runs on your machine. No file content makes any network request.

Collected (anonymous, opt-out)

To see what's used and where people get stuck, Kramata sends a few anonymous product events via Aptabase (privacy-first, open-source):

  • app_opened, sample_loaded
  • file_loaded — file type + a bucketed row count (e.g. “1k–10k”). Never the name or contents.
  • rule_added — the rule type only.
  • recipe_saved/recipe_loaded, batch_run, export
  • error — the error code only (e.g. “CSV_PARSE”). Never the message, file, or data.

There are no accounts, no advertising IDs, and no cross-app tracking. A hard allow-list in the app ensures only bounded values are ever sent — file data physically cannot leave.

Turn it off

In the app: Settings & privacy (gear icon, top-right) → uncheck “Share anonymous usage stats”. Effective immediately.

Licensing

Kramata Pro (the Batch feature) uses Gumroad license keys. When you activate a key, it's verified once with Gumroad and then stored locally on your machine.
